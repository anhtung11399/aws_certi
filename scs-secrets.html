SCS-C03Domain 5 · Data Protection (18%)Bài 1350 phút

Secrets, che dữ liệu nhạy cảm và chứng chỉ

Secrets Manager và rotation, Parameter Store, che dữ liệu bằng CloudWatch Logs / SNS data protection, Macie, ACM, Private CA nhiều Region.

Học xong bài này bạn sẽ:
  • Quản lý và xoay vòng secret
  • Che dữ liệu nhạy cảm
  • Quản lý chứng chỉ

#Secrets Manager

  • Lưu secret (mật khẩu DB, API key, token) mã hoá bằng KMS (aws/secretsmanager hoặc customer managed key; chia sẻ cross-account bắt buộc customer managed key).
  • Rotation: Lambda rotation function theo lịch (rate / cron, tối thiểu 4 giờ). Managed rotation cho RDS, Aurora, Redshift, DocumentDB (khi RDS quản lý master password với ManageMasterUserPassword, không cần Lambda riêng).
  • Bốn bước của rotation: createSecret → setSecret → testSecret → finishSecret. Phiên bản có nhãn AWSPENDING, AWSCURRENT, AWSPREVIOUS.
  • Chiến lược: single user (đổi mật khẩu của chính user, có thể gián đoạn ngắn) và alternating users (hai user luân phiên, không gián đoạn, cần secret admin để tạo / đổi user).
  • Lambda rotation phải gọi được cả database (cùng VPC / SG cho phép) và endpoint Secrets Manager (VPC endpoint hoặc NAT). Đây là nguyên nhân số một của rotation thất bại.
  • Replica secret sang Region khác (DR), tự đồng bộ khi primary đổi.
  • Resource policy cho cross-account; kiểm tra bằng Access Analyzer; BlockPublicPolicy.
  • Ứng dụng đọc: SDK + caching client (giảm gọi API), Lambda extension, CSI driver trên EKS, ECS secrets, CloudFormation dynamic reference.
  • Xoá secret có thời gian chờ (7-30 ngày) để khôi phục.

#Chứng chỉ

  • ACM public certificate: miễn phí, tự gia hạn với DNS validation, không xuất private key (trừ chứng chỉ exportable trả phí mới), gắn ELB / CloudFront (us-east-1) / API Gateway / App Runner. Imported certificate không tự gia hạn: theo dõi event ACM Certificate Approaching Expiration (45 ngày trước) và Config rule.
  • ACM private certificate từ Private CA, tự gia hạn khi được dùng trong dịch vụ tích hợp.
  • Regional: cần ở nhiều Region thì yêu cầu ở từng Region.
  • Chứng chỉ trên EC2 tự quản lý: dùng Private CA + công cụ tự động (cert-manager trên EKS với AWS Private CA issuer), ACM for Nitro Enclaves.
  • CAA record trong DNS để chỉ CA được phép cấp chứng chỉ cho tên miền.

#Tìm và loại bỏ secret bị viết cứng

  • Quét code: CodeGuru Security / Amazon Q, git-secrets, quét trong pipeline.
  • Quét image / Lambda: Inspector code scanning.
  • Phát hiện key lộ công khai: AWS tự quét GitHub công khai và gửi Health event + quarantine policy.
  • Thay bằng: role (EC2 / Lambda / ECS / EKS), Secrets Manager, OIDC cho CI bên ngoài.

SNS data protection kiểm tra và chặn / che dữ liệu nhạy cảm trong message.
