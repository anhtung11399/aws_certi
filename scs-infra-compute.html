Bảo mật compute, container, pipeline và GenAI

AMI / container hardening, instance profile / service role / execution role, Inspector, GuardDuty Runtime, Patch Manager, Session Manager / EC2 Instance Connect, bảo mật pipeline, guardrails cho ứng dụng GenAI.

Học xong bài này bạn sẽ:
  • Giảm bề mặt tấn công của compute
  • Quản lý lỗ hổng liên tục
  • Bảo vệ ứng dụng GenAI

#Image cứng hoá (hardened AMI và container image)

  • EC2 Image Builder: component hardening có sẵn (CIS Benchmark, STIG), cài agent (SSM, CloudWatch, bảo mật), test, quét Inspector, phân phối AMI mã hoá bằng customer managed key cho các account / OU; tự chạy lại khi có bản vá.
  • Gỡ phần mềm / dịch vụ thừa, tắt đăng nhập mật khẩu, không nhúng secret vào image.
  • Allowed AMIs (cấu hình account hoặc declarative policy): chỉ cho launch AMI từ nguồn tin cậy. Block public access for AMIs / snapshots.
  • Container image: base image tối giản (distroless, minimal), chạy user không phải root, ECR enhanced scanning (Inspector), tag immutability, ký image (AWS Signer / Notation) và kiểm tra chữ ký khi deploy (Kyverno / admission controller trên EKS).
  • Kiểm tra và áp cấu hình liên tục: SSM State Manager, Config rule (ec2-instance-managed-by-systems-manager, approved-amis-by-id).

#Quét lỗ hổng và giám sát runtime

  • Inspector: EC2 (agent SSM hoặc agentless), ECR (khi push và liên tục khi có CVE mới), Lambda (thư viện và code). Kết quả vào Security Hub, EventBridge.
  • GuardDuty Runtime Monitoring: hành vi lúc chạy trên EC2, ECS, EKS (tiến trình lạ, reverse shell, đào coin, leo thang đặc quyền). Malware Protection: quét EBS khi nghi ngờ.
  • Kết hợp: Inspector cho biết "có lỗ hổng", GuardDuty cho biết "đang bị khai thác".

#Vá lỗi tự động và kiểm chứng liên tục

  • Patch Manager + patch baseline + maintenance window / patch policy cho Organization; báo cáo compliance.
  • Vòng khép kín: Inspector phát hiện CVE → EventBridge → SSM Automation vá (hoặc thay bằng AMI mới qua ASG instance refresh) → Inspector quét lại, finding tự đóng khi đã vá.
  • Immutable infrastructure: thay vì vá tại chỗ, dựng AMI / image mới và thay instance / task.
  • Lambda: cập nhật runtime khi hết hỗ trợ, cập nhật thư viện; ECS / EKS: rebuild image, cập nhật AMI node.

#Bảo mật trong pipeline (shift-left)

  • Amazon Q Developer (security scanning trong IDE / review code), Amazon CodeGuru Security (SAST: lỗ hổng, secret viết cứng trong code), tích hợp CodePipeline / GitHub Actions.
  • Quét IaC: cfn-guard, cfn-lint, Checkov; quét dependency (SCA) và image (Inspector CI/CD integration) trước khi push.
  • Access Analyzer custom policy checks: chặn merge khi IAM policy mới cấp quyền nguy hiểm.
  • Code signing cho Lambda (AWS Signer, signing profile, code signing config chỉ cho deploy code đã ký).
  • Secret trong pipeline: lấy từ Secrets Manager, không ghi vào biến môi trường build ở dạng rõ, OIDC thay access key cho CI bên ngoài.
  • Bảo vệ chính pipeline: role của CodeBuild / CodePipeline tối thiểu, artifact bucket mã hoá, chỉ nhánh được bảo vệ mới deploy production, phê duyệt thủ công.

#Bảo vệ ứng dụng GenAI

OWASP Top 10 for LLM Applications gồm: prompt injection, lộ thông tin nhạy cảm, chuỗi cung ứng, đầu độc dữ liệu / mô hình, xử lý đầu ra không an toàn, quyền tác tử quá mức (excessive agency), lộ system prompt, điểm yếu vector / embedding, thông tin sai lệch, tiêu thụ tài nguyên không giới hạn.
