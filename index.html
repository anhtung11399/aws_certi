Ôn thi AWS bằng tiếng Việt: CloudOps và Security

Lộ trình dành cho người đã có SAA-C03, muốn thi tiếp AWS Certified CloudOps Engineer – Associate (SOA-C03) và AWS Certified Security – Specialty (SCS-C03). Bài học viết bằng tiếng Việt, giữ nguyên thuật ngữ tiếng Anh như trong đề thi. Học tuần tự từng domain, mỗi bài có câu hỏi kiểm tra nhanh, học xong thì vào phần luyện đề.

#Nên học chứng chỉ nào trước

Gợi ý: thi SOA-C03 trước. Phần CloudWatch, Config, CloudTrail, Systems Manager, VPC của SOA là nền tảng mà SCS hỏi sâu thêm. Học xong SOA, các bài Detection, Logging, Incident Response của SCS sẽ nhẹ đi nhiều.

Cách học hiệu quả: mỗi ngày 1 bài. Đọc bài, làm câu hỏi cuối bài, rồi vào phần luyện đề chọn đúng domain vừa học. Câu nào sai thì đọc kỹ giải thích. Học xong cả lộ trình, làm thi thử 65 câu, đạt từ 80% trở lên vài lần là đủ tự tin đăng ký thi.

SOA-C03

#CloudOps Engineer – Associate

Vận hành hệ thống trên AWS: giám sát, tự động khắc phục, độ tin cậy, triển khai bằng IaC, bảo mật vận hành và mạng.

65 câu (50 tính điểm + 15 không tính), 130 phút, điểm đậu 720/1000 · 20 bài, khoảng 20 giờ đọc

Bài 00Đề SOA-C03 và cách học

Cấu trúc đề, 5 domain, khác SAA-C03 ở đâu, lộ trình học.

Đã học
1

Domain 1 · Monitoring, Logging, Remediation, Performance (22%)

CloudWatch, EventBridge, Systems Manager, tối ưu hiệu năng compute, storage, database.

Bài 01CloudWatch metrics và alarms

Metric có sẵn và custom, resolution, CloudWatch agent (cấu hình chi tiết), alarm, composite alarm, anomaly detection, metric math, dashboards nhiều account.

Đã họcBài 02CloudWatch Logs, tracing và observability

Log group, retention, metric filter, Logs Insights, subscription, export, Embedded Metric Format, X-Ray, Application Signals, Synthetics, RUM, Container / Lambda Insights, Prometheus, Grafana, CloudTrail cho vận hành.

Đã họcBài 03EventBridge: tự động hoá theo sự kiện

Event bus, event pattern, target, input transformer, cross-account / cross-Region, Scheduler, Pipes, archive và replay, AWS Health, xử lý sự cố rule.

Đã họcBài 04Systems Manager toàn tập

Managed node, Run Command, Automation runbook, Patch Manager, State Manager, Maintenance Windows, Session Manager, Parameter Store, Inventory, OpsCenter, Incident Manager, Distributor, Change Manager, hybrid activation.

Đã họcBài 05EC2: chẩn đoán và tối ưu

Instance family, status check, lỗi khởi chạy, placement group, ENA / EFA, burstable, Nitro, Capacity Reservation, Spot, Compute Optimizer, chi phí.

Đã họcBài 06Storage: EBS, S3, EFS, FSx, DataSync

Loại EBS và giới hạn, Elastic Volumes, snapshot, FSR, S3 performance, multipart, Transfer Acceleration, lifecycle, storage class, EFS / FSx, DataSync, Storage Gateway.

Đã họcBài 07Database: RDS, Aurora, DynamoDB, ElastiCache

Metric, Performance Insights, Enhanced Monitoring, RDS Proxy, parameter group, read replica, Multi-AZ, Aurora, DynamoDB capacity và throttle, DAX, ElastiCache.

Đã học
2

Domain 2 · Reliability & Business Continuity (22%)

ELB, Auto Scaling, Route 53, backup và DR.

Bài 08Load balancer và Auto Scaling

ALB / NLB / GWLB, target group, health check, mã lỗi, access log, stickiness, cross-zone, TLS; ASG: policy, lifecycle hook, warm pool, instance refresh, health check, xử lý sự cố.

Đã họcBài 09Route 53 và tính sẵn sàng nhiều Region

Hosted zone, record, alias, routing policy, health check, DNS failover, Application Recovery Controller, thiết kế Multi-AZ / Multi-Region.

Đã họcBài 10Backup và khôi phục thảm hoạ

RPO / RTO, 4 chiến lược DR, AWS Backup chi tiết, khôi phục từng dịch vụ, S3 versioning / replication, Elastic Disaster Recovery.

Đã học
3

Domain 3 · Deployment, Provisioning & Automation (22%)

CloudFormation, CDK, StackSets, AMI, chiến lược deploy.

Bài 11CloudFormation chuyên sâu

Template, intrinsic function, pseudo parameter, dynamic reference, change set, drift, stack policy, rollback, helper scripts, nested stack, StackSets, lỗi và cách xử lý, CDK, Terraform.

Đã họcBài 12AMI, container image và chia sẻ tài nguyên

EC2 Image Builder, quản lý AMI, ECR, chia sẻ AMI / snapshot, AWS RAM, Service Catalog, Service Quotas.

Đã họcBài 13Deploy và vận hành ứng dụng

Chiến lược deploy, Elastic Beanstalk, CodeDeploy, ECS / EKS / Lambda ở góc vận hành, automation hướng sự kiện.

Đã học
4

Domain 4 · Security & Compliance (16%)

IAM, KMS, Config, các dịch vụ bảo mật ở góc nhìn vận hành.

Bài 14IAM và bảo mật trong vận hành

IAM troubleshooting, policy, role, MFA, Organizations / SCP, Identity Center, Access Analyzer, credential report, KMS, ACM, Secrets Manager.

Đã họcBài 15Tuân thủ: Config, Security Hub, GuardDuty, Inspector

AWS Config chi tiết, remediation, conformance pack, aggregator; Security Hub, GuardDuty, Inspector, Macie, Trusted Advisor, CloudTrail.

Đã học
5

Domain 5 · Networking & Content Delivery (18%)

Xử lý sự cố VPC, kết nối lai, Route 53 Resolver, CloudFront.

Bài 16VPC và xử lý sự cố mạng

Subnet, route table, IGW, NAT, SG vs NACL, VPC endpoint, Flow Logs, Reachability Analyzer, IPv6, IPAM, VPC sharing, các lỗi kết nối kinh điển.

Đã họcBài 17Kết nối lai và DNS

VPC peering, Transit Gateway, Site-to-Site VPN, Direct Connect, Client VPN, PrivateLink, Route 53 Resolver endpoints và rules, DNS Firewall.

Đã họcBài 18CloudFront, WAF, Shield và Global Accelerator

Cache behavior, cache / origin request policy, TTL, invalidation, OAC, signed URL, lỗi 4xx / 5xx, edge function, WAF rule, Shield, Global Accelerator.
