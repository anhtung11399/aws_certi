Event pattern

Pattern là JSON có cùng cấu trúc với event, giá trị là mảng các giá trị chấp nhận. Event khớp khi mọi trường trong pattern khớp.

Kiểu lọcVí dụ
Bằng một trong nhiều giá trị"state": ["stopped", "terminated"]
Tiền tố / hậu tố"bucket": [{ "prefix": "logs-" }], { "suffix": ".jpg" }
Phủ định"state": [{ "anything-but": "running" }]
Số"severity": [{ "numeric": [">=", 7] }]
Tồn tại / không"errorCode": [{ "exists": true }]
Wildcard"eventName": [{ "wildcard": "Delete*" }]
Không phân biệt hoa thường{ "equals-ignore-case": "admin" }
{
  "source": ["aws.ec2"],
  "detail-type": ["AWS API Call via CloudTrail"],
  "detail": {
    "eventSource": ["ec2.amazonaws.com"],
    "eventName": ["AuthorizeSecurityGroupIngress", "DeleteSecurityGroup"]
  }
}

Event "AWS API Call via CloudTrail" chỉ có với API ghi (không có Get / List / Describe) và chỉ khi có CloudTrail ghi management events. Dịch vụ global (IAM, STS global, CloudFront, Route 53, Organizations) sinh event ở us-east-1.

Target

  • Lambda, SNS, SQS (kể cả FIFO), Kinesis Data Streams / Firehose, Step Functions, ECS task, Batch job, CodeBuild, CodePipeline, SSM Automation / Run Command / OpsItem, API Gateway, API destination (gọi HTTP endpoint bên ngoài có xác thực), event bus khác, CloudWatch Logs log group, Redshift, SageMaker Pipelines, Incident Manager...
  • Quyền gọi target: Lambda, SNS, SQS, Logs dùng resource-based policy cho events.amazonaws.com. Kinesis, Step Functions, ECS, SSM, event bus khác Region / account dùng IAM role gắn với rule.
  • Input transformer: lấy trường từ event (InputPathsMap) rồi ghép thành nội dung mới (InputTemplate). Ví dụ thông báo "Instance <id> vừa chuyển sang <state>".
  • Retry policy (mặc định thử lại 24 giờ, 185 lần) và DLQ (SQS) cho từng target.

Cross-account và cross-Region

  • Gửi event sang bus của account khác: target là ARN của bus đích, bus đích có resource policy cho phép account gửi (hoặc cả Organization bằng aws:PrincipalOrgID).
  • Gửi sang Region khác: target là bus ở Region đích, rule cần IAM role.
  • Mẫu gom sự kiện bảo mật / vận hành: mọi account gửi event về một bus trung tâm ở account vận hành.
  • Global endpoints: tự chuyển việc nhận event sang Region phụ khi Region chính lỗi (cho ứng dụng tự gửi event).

AWS Health

  • AWS Health Dashboard (Your account health): sự cố dịch vụ ảnh hưởng tới tài nguyên của bạn, thay đổi có lịch (bảo trì, retire phần cứng, hết hỗ trợ phiên bản RDS / EKS), thông báo tài khoản.
  • API Health cần gói Business support trở lên; event qua EventBridge thì mọi account đều có.
  • Organizational view: xem Health event của mọi account từ management / delegated admin.
  • Mẫu: Health event "scheduled retirement" → EventBridge → SSM Automation stop / start instance trong maintenance window.

Rule không chạy: checklist

  1. Metric TriggeredRules = 0: pattern không khớp (sai hoa thường, thiếu mảng, sai detail-type), sai Region, event không tồn tại (thiếu CloudTrail, API là Describe).
  2. TriggeredRules có nhưng FailedInvocations tăng: thiếu quyền gọi target (resource policy / role), target bị throttle, KMS của SQS / SNS không cho EventBridge.
  3. Dùng sandbox (Test event pattern) trên console để thử pattern với event mẫu.
  4. Gắn DLQ để xem event không gửi được và lý do.
