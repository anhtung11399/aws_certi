  • Block Public Access ở cấp account (và Organization), Object Ownership = Bucket owner enforced (tắt ACL).
  • Object Lock: Governance mode (người có quyền đặc biệt s3:BypassGovernanceRetention vẫn xoá được), Compliance mode (không ai xoá được, kể cả root, tới hết hạn), Legal hold (giữ vô thời hạn tới khi gỡ). Cần versioning.

  • Thêm: S3 Access Points (policy riêng cho từng nhóm dùng), Access Grants (cấp quyền theo người dùng trong IdP), VPC endpoint policy.

Mã hoá EBS, RDS, DynamoDB

  • EBS: bật encryption by default. Không mã hoá trực tiếp volume đang có: snapshot → copy có mã hoá → volume mới.
  • RDS: chọn mã hoá lúc tạo, không bật sau được (snapshot → copy mã hoá → restore). Read replica cùng trạng thái mã hoá với primary. Ép TLS: parameter rds.force_ssl (PostgreSQL / SQL Server), require_secure_transport (MySQL). Đăng nhập không mật khẩu: IAM database authentication.
  • DynamoDB: luôn mã hoá at rest (AWS owned, AWS managed, hoặc customer managed key).
  • Dữ liệu in transit trong VPC: dùng TLS giữa các thành phần, ALB → target bằng HTTPS, instance Nitro có mã hoá tự động giữa các instance hỗ trợ.

Chứng chỉ TLS

  • ACM: public certificate miễn phí, tự gia hạn (DNS validation). Không xuất được private key của public cert. Gắn cho ELB, CloudFront (phải ở us-east-1), API Gateway.
  • AWS Private CA: tự làm CA nội bộ, cấp chứng chỉ cho dịch vụ nội bộ, mTLS, IoT, Roles Anywhere.
  • Chọn security policy TLS trên ALB / CloudFront để chặn TLS cũ (chỉ TLS 1.2 trở lên, hỗ trợ cả post-quantum).
  • mTLS: ALB và API Gateway hỗ trợ xác thực chứng chỉ client.

Phân loại và vòng đời dữ liệu

  • Phân loại bằng Macie + gắn tag (ví dụ DataClassification=Confidential), dùng tag trong ABAC và trong backup policy.
  • Xoá dữ liệu đúng hạn: S3 lifecycle, DynamoDB TTL, AWS Backup retention.
  • Backup chống ransomware: AWS Backup Vault Lock, logically air-gapped vault (vault tách biệt, chia sẻ khôi phục cho account khác), copy sang account khác.
