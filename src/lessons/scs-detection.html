Nhớ nhanh: GuardDuty = "có kẻ xấu đang làm gì". Inspector = "phần mềm có lỗ hổng". Macie = "dữ liệu nhạy cảm ở đâu trong S3". Security Hub = "bảng tổng hợp + chấm điểm". Detective = "điều tra vì sao". Config = "cấu hình có đúng chuẩn không".

GuardDuty chi tiết

  • Bật một cú cho cả Organization: chỉ định delegated administrator (thường là account Security / Audit), bật auto-enable cho account mới.
  • GuardDuty là dịch vụ Regional: phải bật ở mọi Region, kể cả Region không dùng (kẻ tấn công hay chạy máy đào coin ở Region bạn không để ý).
  • Finding có loại (ví dụ UnauthorizedAccess:IAMUser/InstanceCredentialExfiltration.OutsideAWS: credential của EC2 bị dùng từ ngoài AWS), mức độ (Low / Medium / High / Critical).
  • Giảm nhiễu: trusted IP list (không cảnh báo IP của công ty), suppression rule (tự lưu trữ finding khớp điều kiện), threat list (IP xấu của riêng bạn).
  • Mọi finding gửi tới EventBridge → tự động phản ứng (bài 04). Xuất finding ra S3 để lưu lâu (mã hoá KMS).
  • Extended Threat Detection: gom nhiều tín hiệu thành một chuỗi tấn công (attack sequence).

Security Hub và Security Lake

  • Security Hub cần AWS Config bật để chạy các control kiểm tra chuẩn. Gom nhiều Region về một Region: cross-Region aggregation. Gom nhiều account: delegated admin, central configuration (áp chính sách bật / tắt control cho cả Organization).
  • Automation rules: tự sửa trường của finding (đổi severity, gán workflow status) khi khớp điều kiện. Custom actions: nút bấm gửi finding tới EventBridge.
  • Amazon Security Lake: data lake bảo mật tập trung trên S3, chuẩn hoá log về định dạng OCSF, gom CloudTrail, VPC Flow Logs, Route 53 Resolver logs, Security Hub findings, EKS audit, WAF logs... từ nhiều account / Region. Cho phép subscriber (SIEM bên thứ ba, Athena) truy vấn. Đề nói "data lake bảo mật, định dạng chuẩn, tích hợp công cụ bên thứ ba" → Security Lake.

Giám sát và cảnh báo

  • Cảnh báo theo hành động nhạy cảm: CloudTrail → CloudWatch Logs → metric filter (ví dụ đăng nhập root, đổi security group, tắt CloudTrail, console login thất bại) → alarm → SNS. Đây là các control CIS.
  • Hoặc nhanh hơn: EventBridge rule khớp trực tiếp event CloudTrail.
  • Health check của tài nguyên: Route 53 health check, ELB health check, CloudWatch Synthetics canary.
  • Chạy đánh giá định kỳ: Config conformance pack, Security Hub, SSM State Manager association.
  • Dashboard bảo mật: CloudWatch, Amazon Managed Grafana, OpenSearch Dashboards.
