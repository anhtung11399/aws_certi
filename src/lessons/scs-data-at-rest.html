Mã hoá từng dịch vụ

Dịch vụGhi nhớ
S3Mọi object mới mặc định SSE-S3. Default encryption SSE-KMS + Bucket Key. Ép đúng key bằng bucket policy (s3:x-amz-server-side-encryption-aws-kms-key-id). Đổi mã hoá object cũ: copy lại tại chỗ hoặc S3 Batch Operations
EBSEncryption by default theo Region; snapshot / volume / AMI kế thừa mã hoá; mã hoá volume cũ: snapshot → copy có mã hoá → volume mới
RDS / AuroraChỉ chọn lúc tạo; mã hoá cả backup, snapshot, replica, log. Bật cho DB cũ: snapshot → copy mã hoá → restore. Đổi key: copy snapshot với key mới. Read replica cross-Region dùng key ở Region đích
DynamoDBLuôn mã hoá: AWS owned (mặc định), AWS managed, customer managed; đổi được khi đang chạy
EFSBật lúc tạo, không đổi được sau; mã hoá in transit qua TLS mount
Secrets Manager, SSM SecureString, SQS, SNS, Kinesis, CloudWatch LogsChọn customer managed key để kiểm soát; nhớ key policy cho dịch vụ gọi tới (CloudWatch → SNS mã hoá, EventBridge → SQS mã hoá)
EKS secretsEnvelope encryption bằng KMS key
Lambda biến môi trườngMã hoá at rest mặc định; dùng customer managed key và helper mã hoá ở client cho giá trị nhạy cảm

Vòng đời và lưu giữ tự động

  • S3 Lifecycle: chuyển lớp lưu trữ và xoá theo tuổi, xoá noncurrent version, kết hợp Object Lock để giữ đúng thời hạn rồi mới xoá.
  • EFS lifecycle: chuyển file ít dùng sang IA / Archive.
  • FSx for Lustre: automatic daily backup (persistent), retention, backup ra S3 qua data repository; FSx for Windows / ONTAP / OpenZFS có backup tự động và AWS Backup.
  • DynamoDB TTL: tự xoá item hết hạn (ví dụ dữ liệu cá nhân hết thời gian giữ).
  • CloudWatch Logs retention, Backup lifecycle (cold storage, hết hạn).
  • Xoá đúng hạn để tuân thủ luật bảo vệ dữ liệu: không giữ dữ liệu cá nhân lâu hơn mục đích.

  • AWS Backup: backup policy của Organization, copy cross-Region / cross-account, Vault Lock (governance / compliance), logically air-gapped vault, restore testing, Backup Audit Manager, multi-party approval để khôi phục từ vault air-gapped khi account bị chiếm. GuardDuty Malware Protection có thể quét recovery point.
  • Data Lifecycle Manager: lịch snapshot EBS / AMI theo tag, copy cross-Region / cross-account (snapshot mã hoá: chia sẻ key).
  • S3 Replication sang account khác với owner override (đổi chủ sở hữu bản sao sang account đích), Replication Time Control, replicate cả object mã hoá SSE-KMS (chỉ định key đích).
  • DataSync: chép dữ liệu có mã hoá TLS, kiểm tra toàn vẹn, ghi vào đích mã hoá; agent kích hoạt qua endpoint riêng (VPC endpoint).
  • Ransomware trên S3 (mã hoá lại object bằng SSE-C / key của kẻ tấn công, hoặc xoá): versioning + Object Lock, chặn SSE-C bằng bucket policy, giới hạn s3:PutObject / DeleteObject, GuardDuty S3 Protection.
