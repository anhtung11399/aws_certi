AWS WAF chuyên sâu

Cấu trúc

  • Web ACL gắn vào: CloudFront (global, tạo ở us-east-1), ALB, API Gateway REST, AppSync, Cognito user pool, App Runner, Verified Access, Amplify.
  • Rule xét theo priority (số nhỏ trước). Hành động: Allow, Block (có custom response), Count, CAPTCHA, Challenge (thử thách trình duyệt không cần người). Allow / Block dừng đánh giá; Count tiếp tục.
  • Default action khi không rule nào khớp: Allow (mô hình chặn danh sách đen) hoặc Block (danh sách trắng).
  • WCU (Web ACL Capacity Units): giới hạn độ phức tạp của web ACL (mặc định 1.500, có thể tăng có phí).
  • Label: rule gắn nhãn cho request, rule sau dùng nhãn để quyết định (ví dụ chỉ chặn bot "unverified" ở trang login).
  • Scope-down statement: chỉ áp managed rule group (tốn phí như Bot Control) cho một phần request (path /login).
  • Rule action override: đặt một rule trong managed group sang Count khi nó chặn nhầm.

CloudFront ở góc nhìn bảo mật

  • Origin Access Control (OAC): chỉ CloudFront đọc được S3 private (ký SigV4, hỗ trợ SSE-KMS, mọi Region). Bucket policy cho cloudfront.amazonaws.com với AWS:SourceArn = ARN distribution. OAI là cách cũ.
  • Bảo vệ origin tuỳ chỉnh: SG của ALB chỉ cho managed prefix list com.amazonaws.global.cloudfront.origin-facing; CloudFront thêm custom header bí mật, WAF trên ALB (hoặc listener rule) chặn request thiếu header; xoay vòng header bằng Secrets Manager. Hoặc dùng VPC origins để origin ở private subnet.
  • Viewer protocol policy Redirect / HTTPS only, security policy TLSv1.2_2021 trở lên cho viewer; origin protocol HTTPS only; Origin SSL protocols.
  • Response headers policy: HSTS, Content-Security-Policy, X-Frame-Options, X-Content-Type-Options, Referrer-Policy; CORS (Access-Control-Allow-Origin...) thêm ở edge.
  • Signed URL / signed cookie với key group (public key trong CloudFront, private key ở bạn) cho nội dung trả phí / riêng tư. Field-level encryption mã hoá trường nhạy cảm từ edge tới tận ứng dụng.
  • Geo restriction: allow list / block list quốc gia (trả 403).
  • CloudFront Functions / Lambda@Edge: kiểm tra token, chặn theo header, thêm header bảo mật, chuẩn hoá request.

S3 CORS

CORS cho phép trang ở tên miền khác gọi trình duyệt tới bucket. Cấu hình CORS của bucket là danh sách rule: AllowedOrigins, AllowedMethods, AllowedHeaders, ExposeHeaders, MaxAgeSeconds. CORS không phải cơ chế phân quyền: nó chỉ ảnh hưởng trình duyệt; quyền thật vẫn do bucket policy / IAM quyết định. Đừng đặt AllowedOrigins: * cho bucket có dữ liệu riêng tư.

AWS IoT policies

  • Thiết bị xác thực bằng chứng chỉ X.509 (mTLS), gắn IoT policy vào chứng chỉ: iot:Connect, iot:Publish, iot:Subscribe, iot:Receive trên topic.
  • Dùng policy variables (${iot:Connection.Thing.ThingName}, ${iot:ClientId}) để mỗi thiết bị chỉ publish / subscribe topic của chính nó.
  • AWS IoT Device Defender: audit cấu hình (policy quá rộng, chứng chỉ dùng chung) và detect hành vi bất thường của thiết bị.
  • Thu hồi chứng chỉ thiết bị bị chiếm (đặt INACTIVE / REVOKED).
