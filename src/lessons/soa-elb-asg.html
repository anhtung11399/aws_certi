Target group và health check

Tham sốMặc định ALBGhi nhớ
Protocol / port / pathHTTP, cổng traffic, /Nên dùng path riêng /health kiểm tra cả phụ thuộc quan trọng (nhưng đừng để database chập chờn làm cả đội máy bị đánh dấu hỏng)
Healthy threshold5Số lần thành công liên tiếp để coi là khoẻ
Unhealthy threshold2
Interval / timeout30 / 5 giây
Success codes200Có thể đặt 200-399. Trang chủ redirect 301 / 302 sẽ bị coi là lỗi nếu chỉ chấp nhận 200
  • Trạng thái target: initial, healthy, unhealthy, unused (target ở AZ chưa bật trên LB), draining, unavailable. Mã lý do: Target.Timeout, Target.ResponseCodeMismatch, Target.FailedHealthChecks, Elb.InitialHealthChecking.
  • Deregistration delay (mặc định 300 giây): chờ request đang chạy xong trước khi rút target. Request ngắn thì giảm để deploy / scale-in nhanh hơn.
  • Slow start: target mới nhận tải tăng dần (30-900 giây), hợp ứng dụng cần làm nóng cache / JIT.
  • Thuật toán: round robin, least outstanding requests, weighted random (kèm anomaly mitigation: tự giảm tải cho target bất thường).
  • Stickiness: duration-based cookie (AWSALB) hoặc application cookie. Làm tải lệch giữa các target.
  • Khi tất cả target unhealthy, ALB vẫn gửi tới tất cả (fail open). Có thể cấu hình target group health (DNS failover khi số target khoẻ dưới ngưỡng).

TLS trên load balancer

  • Chứng chỉ từ ACM (hoặc IAM). Nhiều chứng chỉ trên một listener nhờ SNI.
  • Security policy chọn phiên bản TLS và cipher (ví dụ chỉ TLS 1.2 / 1.3, có post-quantum).
  • TLS termination ở LB, hoặc mã hoá lại tới target (HTTPS target group), hoặc NLB TCP passthrough để target tự giải mã.
  • mTLS trên ALB: verify chứng chỉ client với trust store (CA bundle trong S3), hoặc passthrough header.
  • Redirect HTTP → HTTPS bằng rule của listener 80.

Auto Scaling

Thành phần

  • Launch template (khuyên dùng, có version; launch configuration là cách cũ): AMI, instance type, key, SG, user data, IAM instance profile, IMDSv2, tag.
  • Min / max / desired. Nhiều AZ (subnet). Mixed instances policy: nhiều loại máy, kết hợp On-Demand + Spot (on-demand base, %, allocation strategy).
  • Gắn vào target group: ASG tự đăng ký / huỷ đăng ký instance.

Scaling policy

Scale theo hàng đợi SQS: metric tuỳ chỉnh backlog per instance = ApproximateNumberOfMessagesVisible / số instance, target = thời gian xử lý chấp nhận được / thời gian xử lý một message.

Vòng đời instance

[go] Pending / launch -> hook [cache] Pending:Wait / cài đặt, đăng ký, kiểm tra -> CompleteLifecycleAction [ok] InService / nhận tải -> scale-in [warn] Terminating:Wait / xả log, rút khỏi cluster -> [ext] Terminated
  • Lifecycle hook có timeout (mặc định 3600 giây) và default result (CONTINUE / ABANDON). Thông báo qua EventBridge / SNS / SQS → Lambda / SSM làm việc rồi gọi CompleteLifecycleAction (hoặc gia hạn bằng heartbeat).
  • Warm pool: giữ instance đã khởi tạo sẵn ở trạng thái Stopped / Hibernated / Running để scale-out nhanh; có thể trả instance về pool khi scale-in.
  • Instance refresh: thay dần instance theo launch template mới, minimum healthy percentage, checkpoint, tự rollback theo alarm, bỏ qua instance đã khớp.
  • Termination policy mặc định: chọn AZ có nhiều instance nhất, rồi instance có launch template / configuration cũ nhất, rồi gần giờ thanh toán kế tiếp. Có thể tuỳ chỉnh (OldestInstance, NewestInstance...) hoặc dùng Lambda.
  • Scale-in protection cho instance đang xử lý việc dài. Standby: rút tạm khỏi phục vụ để sửa / điều tra, vẫn thuộc ASG.
  • Suspend processes: Launch, Terminate, HealthCheck, ReplaceUnhealthy, AZRebalance, AlarmNotification, ScheduledActions, AddToLoadBalancer. Ví dụ tạm dừng ReplaceUnhealthy để điều tra máy hỏng.
  • Capacity Rebalancing: với Spot, chủ động thay instance có nguy cơ bị thu hồi.
  • Maximum instance lifetime: tự thay instance sau N ngày (vá định kỳ).

Health check

  • Mặc định chỉ EC2 status check. Bật ELB health check để thay máy khi ứng dụng chết. Có thêm EBS health check và VPC Lattice health check.
  • Health check grace period: thời gian chờ sau launch trước khi đánh giá (đặt lớn hơn thời gian khởi động). Ngắn quá → vòng lặp launch / terminate.
  • Đánh dấu tay: set-instance-health --health-status Unhealthy.
