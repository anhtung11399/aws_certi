AWS Config chi tiết

[go] Configuration recorder / ghi lại cấu hình tài nguyên -> configuration item [cache] Config rules / managed hoặc custom (Lambda, Guard) -> NON_COMPLIANT [warn] Remediation / SSM Automation (thủ công hoặc tự động) -> [q] Thông báo / SNS, EventBridge, Security Hub
  • Configuration recorder: ghi mọi loại tài nguyên hoặc chọn loại; tần suất continuous hoặc daily (rẻ hơn). Ghi vào delivery channel (S3 bucket, tuỳ chọn SNS). Cần bật ở mọi Region; tài nguyên global (IAM) chỉ ghi ở một Region để tránh trùng.
  • Configuration timeline: xem cấu hình tài nguyên qua thời gian, kèm liên kết tới CloudTrail event gây thay đổi, quan hệ với tài nguyên khác.
  • Rule trigger: configuration changes (khi tài nguyên đổi) hoặc periodic (1, 3, 6, 12, 24 giờ).
  • Rule: managed rule (hơn 400 rule có sẵn: s3-bucket-public-read-prohibited, encrypted-volumes, restricted-ssh, required-tags, rds-multi-az-support, ec2-instance-managed-by-systems-manager, cloudtrail-enabled, iam-password-policy...), custom Lambda rule, custom Guard rule (cú pháp CloudFormation Guard, không cần Lambda).
  • Proactive evaluation: kiểm tra tài nguyên trước khi tạo (qua CloudFormation Hooks).
  • Remediation: gắn SSM Automation document; tham số lấy từ resource ID; automatic remediation có số lần thử và khoảng thời gian; cần role cho Automation.
  • Conformance pack: bộ rule + remediation dạng YAML (mẫu CIS, PCI DSS, Operational Best Practices...), deploy cho cả Organization.
  • Aggregator: gom dữ liệu Config của nhiều account / Region (theo Organization hoặc danh sách account) về một account, xem compliance tổng hợp, advanced query (SQL trên cấu hình: "liệt kê mọi EBS chưa mã hoá ở mọi account").
  • Config là detective: phát hiện sau khi có. Muốn preventive: SCP, IAM, declarative policy, CloudFormation Hooks / proactive rule.
  • Chi phí: tính theo configuration item ghi nhận và số lần đánh giá rule. Giảm bằng ghi daily, loại trừ loại tài nguyên thay đổi liên tục.

Ba câu hay bị đánh tráo: "ai đã đổi security group" → CloudTrail. "Security group này trước đây cấu hình thế nào" → Config. "Tự động phát hiện và sửa security group mở 22" → Config rule + remediation.

CloudTrail cho tuân thủ

  • Trail multi-Region + organization trail, lưu S3 có versioning / Object Lock, mã hoá SSE-KMS, log file integrity validation.
  • Cảnh báo khi CloudTrail bị tắt: EventBridge rule cho StopLogging / DeleteTrail, Config rule cloudtrail-enabled, SCP cấm.
  • Gửi sang CloudWatch Logs để làm metric filter + alarm (các control CIS).
