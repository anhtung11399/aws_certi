Security group vs NACL

Security groupNACL
Gắn vàoENI (instance, RDS, ALB, endpoint...)Subnet
Trạng tháiStateful: chiều về tự được phépStateless: phải cho phép cả chiều về
RuleChỉ AllowAllow và Deny, đánh số, xét từ nhỏ đến lớn, khớp đầu tiên thì dừng
Mặc địnhSG mới: chặn mọi chiều vào, cho mọi chiều raNACL mặc định: cho tất cả. NACL tự tạo: chặn tất cả
NguồnCIDR, SG khác, prefix listCIDR
  • NACL chặn một IP xấu: thêm rule Deny với số nhỏ hơn rule Allow.
  • NACL phải mở ephemeral ports 1024-65535 cho chiều về (client Linux 32768-60999, Windows 49152-65535, NAT Gateway 1024-65535).
  • SG tham chiếu SG: "DB chỉ nhận từ SG app". Tham chiếu được SG ở VPC peer cùng Region, hoặc qua TGW (tính năng security group referencing).
  • Connection tracking: đổi rule SG không cắt kết nối đang mở đã được theo dõi; NACL cắt ngay.

Công cụ chẩn đoán

VPC Flow Logs

version account-id interface-id srcaddr dstaddr srcport dstport protocol packets bytes start end action log-status
2 111122223333 eni-0abc 10.0.1.25 52.94.1.10 49152 443 6 10 840 1700000000 1700000060 ACCEPT OK
  • Bật ở VPC, subnet hoặc ENI (kể cả ENI của ELB, NAT, RDS, Transit Gateway có flow log riêng). Đích: CloudWatch Logs, S3 (Parquet, partition theo giờ), Firehose.
  • Custom format thêm trường: vpc-id, subnet-id, instance-id, tcp-flags, pkt-srcaddr / pkt-dstaddr (IP thật khi đi qua NAT / ELB), flow-direction, traffic-path.
  • Không ghi: traffic tới DNS của Amazon (.2), metadata 169.254.169.254, DHCP, Windows license activation, time sync 169.254.169.123.
  • Đọc: inbound ACCEPT + outbound REJECT → NACL chặn chiều về. REJECT cả hai chiều → SG hoặc NACL chặn chiều vào.
  • Phân tích bằng CloudWatch Logs Insights, Athena; dữ liệu không thời gian thực (gom 1 hoặc 10 phút).

Reachability Analyzer và các công cụ khác

  • Reachability Analyzer: phân tích tĩnh cấu hình từ nguồn tới đích (instance, ENI, IGW, TGW, VPN, endpoint...), chỉ rõ thành phần chặn (SG, NACL, route). Không gửi gói tin.
  • Network Access Analyzer: tìm các đường truy cập vi phạm yêu cầu ("không có đường từ Internet tới subnet database").
  • Traffic Mirroring: sao chép gói tin thật tới thiết bị phân tích (IDS, gỡ lỗi sâu).
  • Network Manager / Infrastructure Performance: độ trễ giữa AZ / Region của mạng AWS.
  • Trên máy: curl -v, nc -zv host port, traceroute, dig, ss -tnp.

VPC sharing và IPv6

  • VPC sharing (qua RAM): account chủ quản lý VPC / subnet / route; account tham gia tạo EC2, RDS, Lambda... trong subnet được chia sẻ. Giảm số VPC, dùng chung NAT / endpoint.
  • IPv6: dải /56 cho VPC, /64 cho subnet, mọi địa chỉ đều public (định tuyến được), dùng egress-only IGW để chặn chiều vào. Dual-stack hoặc IPv6-only subnet.
  • VPC Block Public Access: chặn mọi đường Internet vào / ra VPC ở cấp account / Region (có ngoại lệ).
