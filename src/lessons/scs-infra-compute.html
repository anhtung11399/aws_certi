Bảo vệ EC2

  • IMDSv2: bắt buộc dùng token phiên (PUT rồi mới GET), chống tấn công SSRF lấy credential của role. Ép buộc: HttpTokens=required trong launch template, mặc định ở cấp account, SCP / declarative policy chặn tạo instance thiếu IMDSv2, Config rule ec2-imdsv2-check. Đặt HttpPutResponseHopLimit=1 (2 nếu chạy container) để container không lấy được credential của host.
  • Không mở SSH / RDP ra Internet: dùng Session Manager (log phiên về S3 / CloudWatch, mã hoá KMS, không cần key pair) hoặc EC2 Instance Connect Endpoint (SSH vào máy private không cần bastion).
  • Máy mất key / không vào được: SSM AWSSupport-ResetAccess hoặc EC2Rescue.
  • Patching: SSM Patch Manager. Lỗ hổng: Inspector (EC2, ECR, Lambda), có SBOM export.
  • Golden AMI: dựng bằng EC2 Image Builder có bước hardening (CIS benchmark), quét Inspector, chỉ cho phép dùng AMI đã duyệt (SCP / declarative policy allowed AMIs).
  • Mã hoá EBS mặc định, chặn chia sẻ AMI / snapshot công khai (block public access for AMIs / snapshots).
  • Nitro Enclaves: môi trường cô lập trong instance để xử lý dữ liệu cực nhạy cảm (khoá, dữ liệu thẻ), có attestation với KMS.

Container và serverless

  • ECR: image scanning (basic khi push, enhanced với Inspector quét liên tục), repository policy, mã hoá KMS, tag immutability, pull through cache cho registry bên ngoài.
  • ECS: task role (quyền cho ứng dụng) khác task execution role (quyền kéo image, đọc secret, ghi log). Secret đưa vào container từ Secrets Manager / Parameter Store, không đặt trong biến môi trường plain text của task definition.
  • EKS: IRSA hoặc EKS Pod Identity để pod có IAM role riêng; EKS access entries thay cho aws-auth ConfigMap; bật audit log của control plane; GuardDuty EKS Protection + Runtime Monitoring; network policy.
  • Lambda: execution role least privilege, resource policy (ai được gọi), code signing (chỉ chạy code đã ký bằng AWS Signer), biến môi trường mã hoá KMS, chạy trong VPC khi cần truy cập tài nguyên private.
  • Chuỗi cung ứng phần mềm: quét thư viện (Inspector cho Lambda / ECR, CodeGuru Security / Amazon Q), ký image, SBOM, chỉ kéo từ registry tin cậy.
