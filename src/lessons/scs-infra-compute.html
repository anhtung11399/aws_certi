Quét lỗ hổng và giám sát runtime

  • Inspector: EC2 (agent SSM hoặc agentless), ECR (khi push và liên tục khi có CVE mới), Lambda (thư viện và code). Kết quả vào Security Hub, EventBridge.
  • GuardDuty Runtime Monitoring: hành vi lúc chạy trên EC2, ECS, EKS (tiến trình lạ, reverse shell, đào coin, leo thang đặc quyền). Malware Protection: quét EBS khi nghi ngờ.
  • Kết hợp: Inspector cho biết "có lỗ hổng", GuardDuty cho biết "đang bị khai thác".

Vá lỗi tự động và kiểm chứng liên tục

  • Patch Manager + patch baseline + maintenance window / patch policy cho Organization; báo cáo compliance.
  • Vòng khép kín: Inspector phát hiện CVE → EventBridge → SSM Automation vá (hoặc thay bằng AMI mới qua ASG instance refresh) → Inspector quét lại, finding tự đóng khi đã vá.
  • Immutable infrastructure: thay vì vá tại chỗ, dựng AMI / image mới và thay instance / task.
  • Lambda: cập nhật runtime khi hết hỗ trợ, cập nhật thư viện; ECS / EKS: rebuild image, cập nhật AMI node.

Bảo mật trong pipeline (shift-left)

  • Amazon Q Developer (security scanning trong IDE / review code), Amazon CodeGuru Security (SAST: lỗ hổng, secret viết cứng trong code), tích hợp CodePipeline / GitHub Actions.
